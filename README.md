Static, responsive website package built from the supplied marketplace listing screenshot.

## Important notes
- No fake phone number, email, pricing, reviews, or certifications were added.
- The contact section uses a lead helper that generates a message the customer can copy into Facebook Messenger, text, or email.
- Once you get the mechanic's real contact info, update the CTA buttons and contact section in `index.html`.
